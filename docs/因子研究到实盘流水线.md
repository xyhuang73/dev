# 因子研究到实盘：常见流水线（简化）

> 本文档概括业界常见的 **研究 → 组合 → 验收 → 样本外/实盘** 分层做法，并说明 **向量化研究管线** 与 **事件驱动仿真** 各自适用的阶段。可与《MiniQMT量化交易系统规划》中的向量/事件回测设计对照阅读。

---

## 1. 因子库 / 单因子研究

**目标**：判断单条（或批量）因子在历史截面上是否具有预测力、是否稳定、经中性化与成本假设后是否仍可取。

以下对「日频截面、IC、分层多空、中性化、向量化管线」分别说明 **含义、典型实现步骤、说明要点**。

**记号约定**：凡 **示意公式** 中出现的字母、下标、运算符与集合记号，均在紧随其后的 **符号定义** 表（或列表）中解释；**同一符号** 在 1.1～1.5 节中 **含义一致**，避免重复定义时可写「见 1.1 节表」。

### 1.1 日频截面（daily cross-section）

**含义**：

- **日频**：以 **交易日 t** 为时间粒度推进；每个 t 独立处理一批股票，不混用不同日期混在一起算排名（除非做时序研究另说）。
- **截面（cross-section）**：在 **同一个交易日 t、同一批可交易标的** 上，比较各股票的因子值高低，或因子与未来收益的关系。与 **时序（time series）** 相对——时序是在 **单只股票** 上沿时间看因子自身或与自身滞后项的关系。

**典型实现步骤**：

1. 准备面板数据：每个 `(date, symbol)` 一行，含行情与用于算因子的字段（开高低收量等）。
2. 对每个 `date` 分组（或按日期循环）：在该日内丢弃停牌、ST、上市过短等不可交易样本（规则按研究设定）。
3. 在该日内计算因子值 \(f_{i,t}\)（i 为股票，t 为日）。
4. 下一日或持有期收益 \(r_{i,t+1}\)（或未来 5 日累计收益等）与 \(f_{i,t}\) 用于 IC、分层等（**标签日** 与 **因子日** 对齐方式要固定，避免前视）。

**示意公式**：

$$
r_{i,\,t\to t+H} = \frac{P_{i,\,t+H}}{P_{i,\,t}} - 1
$$

**符号定义**（本节公式中出现的记号均在此解释）：

| 符号 | 含义 |
|------|------|
| \(t\) | 某个 **交易日**（日历上的交易日期索引）。 |
| \(i\) | **股票** 编号（标的下标）；同一 \(t\) 下 \(i\) 遍历当日有效样本。 |
| \(\mathcal{I}_t\) | 交易日 \(t\) 的 **有效股票集合**（已剔除停牌、ST 等后的研究样本）。 |
| \(f_{i,t}\) | 股票 \(i\) 在 **交易日 \(t\)** 的 **因子值**（已算好、可用于排序或回归的标量）。 |
| \(H\) | **持有期长度**，以交易日个数计（如 \(H=1\) 表示持有到下一有效交易日）；与标签定义绑定。 |
| \(r_{i,\,t\to t+H}\) | 从 \(t\) 到 \(t+H\) 的 **简单收益率**（公式如上）。 |
| \(P_{i,t}\) | 股票 \(i\) 在 **交易日 \(t\)** 的 **可比价格**（常用复权收盘价；与收益定义一致即可）。 |
| \(P_{i,\,t+H}\) | 同一标的在未来第 \(H\) 个定价日上的可比价格（与 \(P_{i,t}\) 口径一致）。 |

**说明**：单因子研究里「截面」是核心视角——因子选股本质是「同一天谁比谁好」，因此以日频截面为主；若研究因子在单票上的持续性，再补充时序指标。

### 1.2 IC 与 Rank IC

**含义**：

- **IC（Information Coefficient）**：在 **某个交易日 t 的截面上**，股票因子值与未来收益（或未来超额收益）之间的 **相关系数**。常对多日 IC 取均值、标准差，看平均预测力与稳定性。
- **Rank IC**：把因子值与收益各自在截面内 **换成秩（排名）** 后再算相关系数，对极端值更不敏感，实务中很常用。

**典型实现步骤**（以「次日收益」为例）：

1. 对每个交易日 t，取当日因子 \(f_{i,t}\) 与 **已实现** 的次日收益 \(r_{i,t+1}\)（或 t+1 开盘至 t+2 开盘等，定义一经固定不改）。
2. 在 t 日截面上对全体有效股票计算 Pearson 相关系数 → 得到 \(IC_t\)；若用排名则得到 \(Rank\ IC_t\)。
3. 对所有 t 得到序列 \(\{IC_t\}\)，报告 **均值 IC、IC_IR（均值/标准差）**、正比例（IC>0 的交易日占比）等。

**示意公式**：

$$
IC_t = \operatorname{Corr}_i\big(f_{i,t},\, r_{i,t+1}\big)
$$

若标签为未来 \(H\) 期收益，则将 \(r_{i,t+1}\) 换成 \(r_{i,\,t\to t+H}\)，与数据口径一致即可。

**Rank IC**：将 \(f_{i,t}\)、\(r_{i,t+1}\) 在截面内分别换成秩 \(\operatorname{rank}(f_{i,t})\)、\(\operatorname{rank}(r_{i,t+1})\) 后，再按上式计算相关系数（或对秩做 Pearson，与 Spearman 秩相关一致）。

$$
IC_{IR} = \frac{\operatorname{mean}_t(IC_t)}{\operatorname{std}_t(IC_t)}
$$

**符号定义**：

| 符号 | 含义 |
|------|------|
| \(IC_t\) | **交易日 \(t\)** 截面上的 **信息系数**（本式中为 Pearson 相关系数）。 |
| \(\operatorname{Corr}_i(\cdot,\cdot)\) | 在 **固定 \(t\)** 下，对下标 \(i\) 在 \(\mathcal{I}_t\) 上取的 **样本相关系数**（Pearson）。 |
| \(f_{i,t}\) | 股票 \(i\) 在 \(t\) 日的因子值（见 1.1 节表）。 |
| \(r_{i,t+1}\) | 与因子 \(f_{i,t}\) **配对** 的未来收益标签（常用「次一交易日」收益；具体开收盘口径固定）。 |
| \(r_{i,\,t\to t+H}\) | 持有 \(H\) 期的未来收益（见 1.1 节）。 |
| \(\operatorname{rank}(\cdot)\) | 在 **当日截面** 内对变量做 **秩**（名次），处理并列名次的方式需与实现一致。 |
| \(\{IC_t\}\) | 每个交易日一个 \(IC_t\)，按时间排成的 **IC 时间序列**。 |
| \(\operatorname{mean}_t\) | 对 **时间下标 \(t\)** 求 **算术平均**（跨样本期内所有有 \(IC_t\) 的交易日）。 |
| \(\operatorname{std}_t\) | 对 **时间下标 \(t\)** 求 **样本标准差**（与 \(\operatorname{mean}_t\) 同一序列）。 |
| \(IC_{IR}\) | **IC 的信息比率**，均值与波动之比；分母为 0 时无定义，需单独约定。 |

**说明**：IC 衡量的是 **线性（或秩）共变**，不直接等于可交易利润；需结合分层、成本再看。多因子时也可看因子间相关性，避免高度共线。

### 1.3 分层多空（十分位 / 五分位组合）

**含义**：

- 在每个交易日 t，按因子值把股票 **分成若干层**（如十组：第一组因子最低，第十组最高）。
- **做多高层、做空低层**（或只做多层、基准对冲）构造 **零投资或近似市场中性** 的组合，用 **各层组合收益差** 衡量因子区分度；这是「因子收益」最直观的实证之一。

**典型实现步骤**：

1. 在交易日 t，对有效股票按 \(f_{i,t}\) **升序或降序** 排名，分成 Q 组（Q=5 或 10 常见）。
2. 每组内 **等权**（或市值加权）形成组合，得到各层从 t 到 t+1（或持有期结束）的组合收益。
3. **多空收益** = 最高组组合收益 − 最低组组合收益（定义哪一端为「高因子」与因子方向一致）。
4. 对全样本期，可得到 **多空收益时间序列**，再算年化、夏普、最大回撤等；也可看 **单调性**（是否从第 1 组到第 Q 组收益单调递增/递减）。

**示意公式**：

$$
w_{i,t}^{(q)} =
\begin{cases}
\dfrac{1}{|G_{q,t}|}, & i \in G_{q,t} \\
0, & \text{否则}
\end{cases}
$$

第 \(q\) 组在持有期内的组合收益 \(R_{q,t}\) 为组内个股收益的加权平均（权重与 \(w^{(q)}\) 一致）。

$$
R^{LS}_{t} = R_{Q,t} - R_{1,t}
$$

若因子定义「值越小越好」，则应对分组方向或上式符号作相应调整。

**符号定义**：

| 符号 | 含义 |
|------|------|
| \(Q\) | **分层组数**（如 5 或 10）；将截面股票按因子值均分或等分为 \(Q\) 桶。 |
| \(q\) | **组的序号**，\(q=1,\ldots,Q\)；约定与「因子高/低」哪一端对应需在文中固定。 |
| \(G_{q,t}\) | 交易日 \(t\) 上属于 **第 \(q\) 组** 的股票 **集合**（由 \(f_{i,t}\) 排序后划分）。 |
| \(\|G_{q,t}\|\) | 集合 \(G_{q,t}\) 的 **元素个数**（该组当日股票数）。 |
| \(w_{i,t}^{(q)}\) | **第 \(q\) 组** 组合在股票 \(i\) 上的 **权重**（本式为组内等权）。 |
| \(R_{q,t}\) | 第 \(q\) 组组合在 **调仓日 \(t\) 至下一调仓或持有期末** 的 **组合收益率**（与 \(r_{i,\cdot}\) 口径一致）。 |
| \(R^{LS}_{t}\) | **多空组合**在 \(t\) 对应持有期上的 **收益差**（本式：第 \(Q\) 组减第 \(1\) 组，对应「高因子组 − 低因子组」的一种约定）。 |
| \(R_{1,t}\)、\(R_{Q,t}\) | 分别为 **最低组**、**最高组**（在「因子越大越优」且 \(q=Q\) 为最高档时）的组合收益。 |
| \(\begin{cases}\cdots\end{cases}\) | **分段函数**：满足行内条件时取上行，否则取「否则」分支的权重值。 |
| \(\in\) | **属于**（集合论记号）：\(i \in G_{q,t}\) 表示股票 \(i\) 落在第 \(q\) 组。 |

**说明**：分层结果比单看 IC 更接近「若按规则交易会长什么样」，但仍常 **不含** 精细交易成本；可后续扣双边换手粗估。

### 1.4 中性化（行业、市值等）

**含义**：

- 因子值往往与 **行业、市值（规模）** 等变量相关；若不做处理，因子收益可能只是在 **补偿行业或大小盘暴露**，而非 alpha。
- **中性化**指在截面上剔除这些 **已知风险维度** 的影响，使因子更「纯粹」。常见说法：**行业中性、市值（规模）中性**。

**典型实现步骤**（思路级，具体公式可任选其一）：

1. **行业中性**：在每个交易日 t，行业内对因子去均值（或减行业均值后再标准化）；或按行业虚拟变量对因子做回归，取 **残差** 作为新因子。
2. **市值中性**：在截面上将因子对 \(\log(市值)\) 做横截面回归，取 **残差** 作为市值中性化后的因子；可与行业中性 **分步或一起做多元回归残差**。
3. 用 **中性化后的因子** 重复 IC、分层，对比中性化前后结论是否仍成立。

**示意公式**：

**行业内去均值**：

$$
\tilde{f}_{i,t} = f_{i,t} - \overline{f}_{s(i),t},\qquad
\overline{f}_{s,t} = \frac{1}{|\{j: s(j)=s\}|}\sum_{j:\, s(j)=s} f_{j,t}
$$

**对数市值横截面回归（残差为中性化因子）**：

$$
f_{i,t} = \alpha_t + \beta_t \,\log(MV_{i,t}) + \varepsilon_{i,t}
$$

**行业虚拟变量 + 对数市值**：

$$
f_{i,t} = \alpha_t + \sum_{k} \gamma_{k,t} D_{i,k,t} + \beta_t \,\log(MV_{i,t}) + \varepsilon_{i,t}
$$

**符号定义**：

| 符号 | 含义 |
|------|------|
| \(f_{i,t}\) | **原始**因子值（中性化前）。 |
| \(\tilde{f}_{i,t}\) | **行业内去均值**后的因子（行业中性的一种）。 |
| \(s\) | **行业** 类别标签（如行业代码）。 |
| \(s(i)\) | 股票 \(i\) 在 \(t\) 日（或静态）所属的 **行业**；若行业随时间变，可记 \(s(i,t)\)。 |
| \(\overline{f}_{s,t}\) | 在交易日 \(t\)，**行业 \(s\)** 内所有股票因子 \(f_{j,t}\) 的 **截面均值**。 |
| \(j\) | 求和时的 **股票下标**，用于遍历同一行业内的样本。 |
| \(\{j: s(j)=s\}\) | **属于行业 \(s\)** 的股票 \(j\) 所构成的集合（读作「满足 \(s(j)=s\) 的全体 \(j\)」）。 |
| \(\|\{j: s(j)=s\}\|\) | 上述集合的 **元素个数**（即行业 \(s\) 内股票数），作 \(\overline{f}_{s,t}\) 的分母。 |
| \(\sum_{j:\, s(j)=s}\) | 对 **属于行业 \(s\)** 的全部股票 \(j\) 求和。 |
| \(\frac{1}{|\cdots|}\) | **个数取倒数**，即对 \(|\{j: s(j)=s\}|\) 个观测取等权平均。 |
| \(\alpha_t\) | 回归在 **交易日 \(t\)** 截面上的 **截距项**（随 \(t\) 变化下标表示每日一回归）。 |
| \(\beta_t\) | 在 **交易日 \(t\)** 截面上，因子对 \(\log(MV)\) 的 **回归斜率**。 |
| \(MV_{i,t}\) | 股票 \(i\) 在 \(t\) 日的 **市值**（总市值或流通市值，与团队口径一致）。 |
| \(\log\) | **自然对数**（亦可用常用对数，全文统一即可）。 |
| \(\varepsilon_{i,t}\) | 回归 **理论残差**；实践中用估计残差 \(\hat{\varepsilon}_{i,t}\) 作为中性化因子。 |
| \(\hat{\varepsilon}_{i,t}\) | \(\varepsilon_{i,t}\) 的 **样本拟合残差**（OLS 等估计），作 **市值中性化后因子**。 |
| \(k\) | **行业虚拟变量** 的下标（行业类别编号，一组 \(K\) 个行业需处理多重共线，常删一列）。 |
| \(D_{i,k,t}\) | 若股票 \(i\) 属于行业 \(k\) 则为 1，否则为 0 的 **0-1 变量**（\(t\) 可变表示行业变迁）。 |
| \(\gamma_{k,t}\) | 行业 \(k\) 在 **交易日 \(t\)** 回归中的 **系数**（与截距、基准行业设定有关）。 |
| \(\sum_k\) | 对全部行业虚拟变量项 **求和**（具体基准与约束依实现而定）。 |

**说明**：中性化方法不唯一；论文与实务会说明所用变量与回归设定。过度中性化可能损失真实信息，需与业务一致。

### 1.5 换手、衰减、覆盖度（粗估可交易性）

**含义（简要）**：

- **换手**：相邻调仓日之间，组合成分变化比例；换手高则成本高。
- **衰减**：因子 IC 或分层收益随持有期拉长而变弱的速度。
- **覆盖度**：每日有多少股票有有效因子值；过低则结果噪声大、容量受限。

**典型实现步骤**：在分层或模拟组合规则下，按日统计换手率；换不同持有期算 IC；统计每日有效样本数。

**示意公式**：

$$
TO_t = \frac{1}{2}\sum_{i} \bigl|w_{i,t} - w_{i,t-1}\bigr|
$$

$$
\text{Cov}_t = \frac{|\{i: f_{i,t}\ \text{有效}\}|}{|\mathcal{I}_t|}
$$

（第一个公式：相邻两期权重常见 **双边** 合计；若中间有自然漂移，可先对 \(w_{t-1}\) 再缩放再比较，以团队规范为准。）

**符号定义**：

| 符号 | 含义 |
|------|------|
| \(TO_t\) | **交易日 \(t\)**（或调仓时点）上的 **组合换手率** 指标（本式为常见定义之一）。 |
| \(w_{i,t}\) | 股票 \(i\) 在 **组合调仓后、交易日 \(t\)** 的 **目标权重**（满足 \(\sum_i w_{i,t}=1\) 或按杠杆缩放）。 |
| \(w_{i,t-1}\) | **上一调仓或上一交易日** 的权重；与 \(w_{i,t}\) 的间隔须与换手定义一致。 |
| \(\sum_i\) | 对 **组合内全部股票**（或全市场，取决于 \(w\) 向量定义域）求和。 |
| \(\|\cdot\|\) | **绝对值**（此处对权重差取绝对值）。 |
| \(\frac{1}{2}\) | 将 **买卖两边** 变动各算一半时常用的 **缩放**，使全文换手口径与业界定义一致。 |
| \(\text{Cov}_t\) | 本式中表示 **覆盖度**（Coverage），非「协方差」；为当日有效因子比例。 |
| \(\{i: f_{i,t}\ \text{有效}\}\) | 交易日 \(t\) 上 **因子值非缺失且通过质量过滤** 的股票 \(i\) 构成的集合。 |
| \(\|\{i:\cdots\}\|\) | 该集合的 **元素个数**（有效因子股票数）。 |
| \(\mathcal{I}_t\) | 交易日 \(t\) 的 **可交易/研究全样本** 集合（见 1.1 节）；分母为当日分母池大小。 |

### 1.6 向量化批处理与 research pipeline

**含义**：

- **向量化批处理**：用 **矩阵 / 表运算**（pandas、polars、NumPy 等）一次对多日期、多标的计算，避免 Python 层逐元素慢循环；适合「日 × 股票」面板上的因子与截面统计。
- **Research pipeline（研究管线）**：从 **原始行情 → 清洗 → 因子表 → IC/分层报表** 的一条 **可重复执行的流水线**（常含固定配置、版本号、输出到文件/数据库）；强调 **可复现、可批跑**，不必等价于 GUI 里的「回测引擎」。

**典型实现步骤**：

1. 数据层：统一频率、对齐交易日历、处理停牌与复权。
2. 因子层：按因子定义生成 `factor` 列（可多因子多列）。
3. 评价层：按日循环或 groupby 计算 IC、分层收益（内部仍尽量向量化）。
4. 产出：IC 序列、分层净值曲线、摘要表；可选落盘供对比实验。

**说明**：管线解决的是 **研究效率与一致性**；与 **事件驱动回测** 互补——前者偏批量研究，偏验证执行时再上后者。

## 2. 组合层（多因子）

**目标**：将多条通过初筛的因子 **合成** 为组合信号，并控制暴露与风险。

**典型做法**：

- **多因子加权**（等权、IC 加权、机器学习权重等）；
- **组合优化**（均值–方差、风险平价、约束下的最优化）；
- 仍以 **矩阵 / 优化器批量计算** 为主，可与第 1 阶段共用数据与代码结构。

**说明**：本层仍偏 **研究与组合构建**，未必引入逐笔委托；重点是 **信号质量与风险结构**。

---

## 3. 策略验收（Strategy acceptance）

**目标**：在 **已选定的交易与风控规则** 下，验证净值、回撤、成交与约束是否 **可落地**。

**典型做法**：

- 将组合信号接入 **明确的买卖、仓位、再平衡与风控规则**；
- 使用 **事件驱动** 或 **准事件**（按 K 线/bar 推进，带成本、滑点、涨跌停等简化）回测；
- 通过后进入 **样本外** 验证，再 **小资金实盘** 试跑。

**与第 1、2 阶段的区别**：这里强调 **执行路径、成本与规则**，而不仅是因子统计性质。

---

## 4. 学术文献 vs 对冲基金产品化

| 维度 | 常见侧重点 |
|------|------------|
| **学术文献** | 组合 **排序**、多空收益差、**横截面回归**（如 Fama–MacBeth 等），重在因子定价与显著性，**通常不是**逐笔订单撮合级仿真。 |
| **对冲基金 / 产品化** | 在通过统计检验后，更强调 **事件级或准事件级仿真**、成本与风控、可执行容量与运营流程。 |

两者并非对立：研究阶段多用排序与回归；落地阶段再补事件仿真。

---

## 5. 与「向量回测 / 事件回测」的对应关系（概念上）

- **向量 / 矩阵式流程**：适合 **第 1、2 阶段** 的批量因子与组合计算（与本项目规划中「截面矩阵、批量检验」一致）。
- **事件驱动回测**：适合 **第 3 阶段** 及以后，在固定规则下检验 **资金曲线与执行现实性**。

**单因子** 既可只在第 1 阶段做 IC/分层（不必事件），也可在第 3 阶段用 **单因子 + 固定规则** 做事件回测；区别在于 **要回答的问题**（统计有效性 vs 可执行 PnL），而非「单因子只能用某一种回测类型」。
