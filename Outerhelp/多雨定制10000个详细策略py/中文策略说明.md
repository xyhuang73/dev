# 多雨定制10000个详细策略py 中文版

本文件夹包含机器辅助生成的多雨定制策略模板库，共 10000 个独立策略文件。

该策略库采用机器辅助方式构建，保留了模型结构标签、策略门控、风险预算和状态识别字段，便于后续接入真实数据训练、筛选和组合优化。

## 文件结构

```text
多雨定制10000个详细策略py/
  中文策略说明.md
  策略目录 10000个.csv
  strategies/
    DUOYU000001 多雨定制核心风险调整动量策略.py
    ...
    DUOYU010000 多雨定制事件ESG资金偏好策略.py
```

## 每个策略py包含什么

每个策略文件都是独立 Python 文件，包含：

- 策略编号和中文名称
- 策略主题和适用范围
- 主要持有观察周期（4-20 个交易日）
- 必需字段声明
- 经济逻辑说明
- 风险提示和数据质量提示
- `describe_strategy()` — 策略元数据
- `compute_strategy_score(data)` — 计算横截面分数和排名
- `build_daily_target_weights(data)` — 生成每日目标权重
- `select_latest_target_weights(data)` — 取最新交易日权重

## 输入数据格式

数据必须是长表：一行 = 一个交易日的一只标的

基础索引字段：`date`, `code`

每个策略需要的具体字段见 `策略目录 10000个.csv` 或单个 `.py` 文件内的 `REQUIRED_FIELDS`。

## 使用示例

```python
import importlib.util
import pandas as pd

file_path = "strategies/DUOYU000001 多雨定制核心风险调整动量策略.py"
spec = importlib.util.spec_from_file_location("strategy_mod", file_path)
mod = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)

data = pd.read_csv("your_panel_data.csv")
score = mod.compute_strategy_score(data)
weights = mod.select_latest_target_weights(data, top_n=5)
print(mod.describe_strategy())
print(weights)
```
